SC64 Theme Maker

Pick colors, a gradient and a pattern, then export a theme.ini for the carousel menu. The preview follows the menu's current 640×480 layout.

Background

Type
Middle color

Use 640×480 for a sharp result. Put the file in the theme folder as background.png. The menu doesn't read PNG backgrounds yet and shows the first color instead.

Pattern

Interface colors

Frame and tabs

The selected row shows on the History preview and in the menu's lists.

Menu features

A theme can switch features on or off. Players can still override each one under Settings, Menu Features.
