SummerStation64 Card Prep

Checks the games on your SD card against the No-Intro list of known good dumps, so the menu can show a Verified badge. Everything happens in this browser: no game is uploaded anywhere.

1Pick your SD card

Choose the top folder of the card (the one with sc64menu.n64 in it). Chrome or Edge can save the result straight onto the card; other browsers can read it and give you the file to copy over.

No card chosen yet.

2The list of known dumps

Downloaded from libretro-database (No-Intro's Nintendo 64 list). Without internet, load the file Nintendo - Nintendo 64.dat yourself.

Downloading…

3Check the games

Every game is read in full, so this takes a minute or two for a full card. Games checked before are skipped, so running it again after adding games is quick.

4Save the result to the card

Writes menu/verified.txt, which the menu reads at start-up.

What was found

Verified: exactly a known good dump. Not a known dump: the game is in the list, but this file differs: a hack, a translation, a patched or a bad dump. Not in the list: homebrew, prototypes and the like.
