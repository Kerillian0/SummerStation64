      Sounds
      
    
      Give a theme its own music and button sounds. Pick any audio files your browser can play (MP3, WAV, OGG, M4A...);
      they are turned into the console's sound files here. Everything happens in this browser: nothing is uploaded anywhere.
      
  
      

  
      
    
      
      
      1Name the theme
      
      
      Sounds belong to a theme on the card, in its own folder: menu/themes/name/, beside its
        theme.ini (make one in the Theme Maker). Use the theme's folder name exactly.
      
      
      
    
      

    
      
      
      2Pick the sounds
      
      
      Pick only the ones you want to change; the menu uses its own for the rest. Music loops; long files are cut
        (music after 3 minutes, the intro after 8 seconds, button sounds after 1.5 seconds). Button sounds are kept in the
        console's memory, so keep them short: under 0.75 seconds also works on consoles without the Expansion Pak.
      
      
      Only the music should loop. The files this page makes never ask to loop; the menu loops the
        music itself. If you make a .wav64 another way (libdragon's audioconv64), leave out any loop for the
        intro and the button sounds: a WAV with a loop point (a smpl marker, set in some audio editors) keeps
        it, and that sound may then repeat.
      
      
      
        
      SoundFileReady

        Pick at least one sound.
      
      
      
      Unzip it at the top of the SD card: the files land in menu/themes/name/. Then choose
        the theme in Settings > Display > Theme. A theme can also carry its own text font as
        font.font64, made with libdragon's mkfont (it applies after a restart).

        SD card setup
        
      
          
        
        1. Back up your card, and keep your current sc64menu.n64 somewhere safe so you can go back.
          2. 
        
        2. Format: the SummerCart64 reads FAT32 and exFAT cards. A card that already works with the cart is fine as it is.
          3. 
        
        3. The menu: download sc64menu.n64 from the
          latest release and copy it to the top folder of the card,
          replacing the one there. The plain sc64menu.n64 is the Art Edition (box covers built in); the Standard zip is a
          small download that reads covers from the card.
          4. 
        
        4. Games: put them in a folder, for example N64. On the console, open the Folders tab, go into that folder,
          press Z and choose Set current directory as default; the Games tab now shows its games as covers. More folders can be
          added the same way with Add this folder to Games.
          5. 
        
        5. Standard edition only: download the
          metadata pack and copy its metadata folder
          into the card's menu folder (menu/metadata/).
          6. 
        
        6. Optional: run Card Prep once to give each game a check mark for a known good dump, and make a theme in the
          Theme Maker (each theme in a folder of its own, menu/themes/My Theme/theme.ini, then picked in Settings > Display > Theme).
          7. 
      
        
      
        Your saves stay where they are. Before each game starts, the menu also keeps a dated copy of its save in
        saves/backups/ (five per game); a game's Options menu has Restore save.
        
    
        

    
        
      
        Box art and details
        
      
        Every game can have its own pictures (front, back, top label, cartridge) and details (developer, release date,
        description). The Art Edition has them built in for most N64 games; for the rest, and for 64DD disks, NES, SNES,
        Game Boy and homebrew, you add your own. The console finds what is missing and this page fills it in.
        
      
        Step by step
        
      
          
        
        1. Make the list on the console. Open Settings > Library > Find Missing Metadata and stay on
          that page until it says it is done (a few seconds). Missing Metadata underneath says how many games lack
          something. The list is saved as menu/missingart.txt on the card.
          2. 
        
        2. Put the card in your computer (switch the console off first).
          3. 
        
        3. Open the Missing Metadata tab and press Choose SD card. Pick the
          top folder of the card, the one holding sc64menu.n64 and the menu folder.
          
            
            
          • Chrome or Edge can save straight to the card: allow it to edit the folder when asked.
            • 
            
          • Firefox, Safari and others ask to "upload" the folder. Nothing leaves your computer: the page only
              reads it. They can't write to the card, so you get a .zip to copy at the end.
            • 
          
          
          The page lists every game with what it lacks. Pick a system or "Missing the front cover" to narrow it.
          4. 
        
        4. Fill in details automatically (optional). Fill details from libretro fills NES, SNES and Game Boy
          games' developer, date, genre and players. Fill from LaunchBox's Metadata.zip also has descriptions and
          covers N64 and 64DD games: download Metadata.zip from the
          LaunchBox Games Database yourself
          and choose it. Only what is missing is filled in.
          5. 
        
        5. Fill in a game. Press Fill in beside it. Choose a picture for each slot from your computer (PNG or
          JPG, any size: the page shrinks it to fit). For a top label or spine, the frame editor lets you zoom, move and
          turn it until it fits; Use for the other edges too puts it on the box's other sides. Type the developer,
          date and description if you have them. Press Keep. Do the same for other games.
          6. 
        
        6. Save. Press Save to card. With Firefox and others, unzip art-for-sd-card.zip into the
          card's top folder (it holds a menu folder that merges with yours).
          7. 
        
        7. Check on the console. Run Find Missing Metadata again: the games you filled in drop off the list.
          8. 
      
        
      
        The pictures

        Back of the boxboxart_back.pngShown when the box is turned over, and on the 3D box's back.
        
          
        Top labelboxart_top.pngThe strip on the 3D box's top (and bottom). A long, thin picture.

        Details go in metadata.ini beside the pictures, and a long description in description.txt.
        
      
        Where the files go (to do it by hand)
        
      
          
        
        • N64 games: menu/metadata/ and the four letters of the game's code, one folder each:
          code NSME goes in menu/metadata/N/S/M/E/. A game's code is in its Game info, START
          (Details).
          • 
        
        • 64DD disks: the same, with the disk's ID (in its Details): menu/metadata/E/F/Z/J/.
          • 
        
        • NES, SNES, Game Boy: menu/metadata/nes/ (or snes, gb,
          gbc) and a folder named like the game's file without its ending:
          Super Metroid (USA).sfc → menu/metadata/snes/Super Metroid (USA)/.
          • 
        
        • Homebrew: pictures in menu/metadata/homebrew/ and the title the game gives itself; details
          in a file beside the game named like it, ending .metadata.ini
          (Game.z64 → Game.metadata.ini). The page does this for you.
          • 
        
        • ROM hacks share their original's code, and so its cover. To give a hack its own, set it up in the
          Hacks tab first, then run Find Missing Metadata.
          • 
      
        
      
        A metadata.ini looks like this:
        
      
        [meta]
name = Super Mario 64
author = Nintendo EAD | Nintendo
release-date = 1996-06-23
genre = Platform
num-players = 1
short-desc = Mario explores Princess Peach's castle.
        
      
        My picture doesn't show
        
        Check the file name (all lower case, .png; the menu reads PNG only, so convert a JPG made by hand) and
          the folder. On the Art Edition, built-in covers come first: a picture on the card only shows for games without
          one. To use your own art for every game, use the Standard edition.
        
      
        The page says there's no menu/missingart.txt
        
        Run Find Missing Metadata on the console first, and pick the card's top folder (picking the menu folder
          works too, but then 64DD and emulator games can't be found).
        
    
        

    
        
      
        64DD disks
        
      
        Put .ndd disk images in a folder and add it to the Games tab like any other (Folders tab, Z,
        Add this folder to Games). Disks show as covers, under the 64DD filter step (C-up / C-down).
        
      
        Expansion disks and their cartridge
        
      
        Some disks add to a cartridge game and need that cartridge to play: the F-Zero X Expansion Kit needs
        F-Zero X. The menu pairs them by itself when the cartridge is in one of the Games tab's folders, and
        A on the disk starts both.
        
      
          
        
        1. Put the cartridge (F-Zero X, Japanese or US) in a Games folder, and the disk in a Games folder too.
          2. 
        
        2. Open the disk's Game info. The third box says Plays with and the cartridge, in green. If it says
          Needs (not found) in orange, the cartridge isn't on the Games tab.
          3. 
        
        3. To choose a cartridge yourself, press Z on the disk's Game info (or R Options there,
          Pair with a cartridge...). Cartridges that match the disk are listed first, in blue. Automatic goes
          back to the menu's own choice; No cartridge plays the disk alone.
          4. 
        
        4. A plays the disk with its cartridge. L (or Options, Play the disk alone) starts the disk
          without it.
          5. 
      
        
      
        Starting an expansion disk without its cartridge shows a warning first: Z there pairs it,
        A starts the disk anyway.
        
    
        

    
        
      
        Cheats
        
      
        The menu runs GameShark and Action Replay codes. They need the Expansion Pak (the codes live in
        its memory). The cart doesn't come with any: each game's codes go in a small text file beside it.
        
      
          
        
        1. Put codes on the card. Open the Cheats tab, pick the card and a game. The page fetches
          that game's codes from libretro-database;
          tick the ones you want (and any enable code the list has), or paste codes from elsewhere, such as
          GameHacking.org. Save to card writes
          Game.datel beside the game.
          2. 
        
        2. Switch them on. On the console, open the game's Game info and press Z (Cheats): a list of the
          game's cheats. A switches one on or off (✓), B closes the list and saves. Switching any cheat on
          turns Use Cheats on for the game; switching them all off turns it off. An orange Cheats badge
          shows on the page while they're on.
          3. 
        
        3. Play. The cheats that are on run from the start.
          4. 
      
        
      
        By hand
        
      
        The file is named like the game with .datel at the end (Super Mario 64 (USA).z64 →
        Super Mario 64 (USA).datel), one code per line, an optional name after it:
        
      
        8033B21D 0064 Infinite lives
80207723 0001 120 stars
8020770B 00C7
        
      
        A line starting : is a code switched off (the console's list writes these); # starts a
        comment. To type codes in on the console, turn on Settings > System > Advanced Game Options: Game
        info's R menu then has the Datel Code Editor.
        
      
        A cheat doesn't work
        
        Keep the list's enable code ticked ("Must be on", or codes starting F1, FF or EE). Codes that need a button held
          (starting D0 to D3) may not work yet, and codes starting DE are skipped. The menu reads up to 64 code lines per
          game. Some games, mostly new homebrew, can't take cheats at all. Codes from a list made for another region or
          version of the game usually don't work: pick the list that matches your copy.
        
    
        

    
        
      
        Hardware
        
      
        Expansion Pak or Jumper Pak
        
      
        SummerStation64 runs fully on a console without the Expansion Pak (with the Jumper Pak, 4MB). With 4MB it picks the smaller
        character set and leaves out a few extras when memory runs short, such as art on the side covers; Settings > System > Memory
        says what was left out. Some games need the Expansion Pak themselves (Majora's Mask, Donkey Kong 64, most of Perfect Dark); the menu
        warns before starting them. Third-party Expansion Paks work the same as Nintendo's.
        
      
        SD card
        
      
        Any reliable card will do; speed matters little, because the menu reads small files. Size: the Art Edition is about 35 MB and games are
        4 to 64 MB each, so even a small card holds a full library. Buy from a trusted seller: fake cards that report more space than they have
        are common and lose files.
        
      
        Picture
        
      
          
        
        • Composite works well: the menu is designed and tested on a small composite CRT.
          • 
        
        • S-Video is sharper and works on NTSC consoles with the right cable; RGB needs a PAL console or a modded NTSC one.
          • 
        
        • HDMI mods and adapters, and upscalers (RetroTINK, OSSC and the like), work too. Try Settings > Display > Video Output:
          240p for a sharper, steadier picture on CRTs and upscalers (it applies after a restart).
          • 
        
        • Analogue 3D and ModRetro M64: players report v0.1 working on both. Not tested here, so reports of anything odd are very welcome.
          • 
      
        
      
        Controllers
        
      
        The menu answers to any controller. Hold START for a second to save a screenshot to menu/screenshots/
        on any controller. If START switches your controller off (the 8BitDo mod kit, for
        one), set Settings > System > Screenshot Button to Hold L + R. With two or more controllers plugged in, the Games tab gets a
        Party filter step for games that many can play.
        
    
        

    
        
      
        Tools
        
      
        SummerCart64 deployer
        
        The cart's own PC tool (sc64deployer, from the
          SummerCart64 releases), over USB: update the cart's firmware,
          and read the menu's debug log with sc64deployer debug --no-writeback, the most useful thing to add to a bug report.
        
      
        Metadata pack
        
        Covers, descriptions and release dates for the Standard edition:
          n64-flashcart-menu-metadata. The Art Edition has them built in.
        
      
        Checking a game file
        
        Card Prep checks every game on the card at once. To check one file by hand, work out its CRC32 or SHA-1 and compare
          it with No-Intro's list (DAT-o-MATIC):
        
        
          
          
        • Windows: certutil -hashfile "Game.z64" SHA1 in a command prompt, or 7-Zip's right-click CRC SHA menu.
          • 
          
        • macOS and Linux: shasum "Game.z64" or sha1sum "Game.z64".
          • 
        
        
        
        No-Intro lists the .z64 byte order. A .v64 or .n64 file has its bytes in another order, so its
          sums differ even when the game is fine; Card Prep allows for that.
        
      
        Theme share codes
        
        The Theme Maker turns a theme into a short code (SS64-…) that others can paste into the same page.
        
    
        

    
        
      
        Troubleshooting
        
      
        Something looks wrong after changing a theme or setting
        
        Hold Z while switching the console on: Safe Mode starts the menu without the theme, your settings and the background
          picture. Nothing on the card is changed.
        
      
        The menu doesn't start
        
        Check that sc64menu.n64 is in the card's top folder and copied in full. Keep the cart's firmware up to date with the
          deployer. To go back, copy your old sc64menu.n64 over it.
        
      
        A game has no cover, or the wrong one
        
        The Art Edition has covers for the games in the metadata pack; others show a plain box. With the Standard edition, check that the pack is
          in menu/metadata/. To add a missing one, see Box art and details. A few games share a code with
          another region's game and can show its cover; this is being fixed.
        
      
        What do the ✓, ? and ✗ marks mean?
        
        They come from Card Prep. ✓: exactly a known good dump. ?: the file differs from the known dump. Often that is harmless
          (an old tool changed a header byte, or the file is padded), but if the game misbehaves, try another copy. ✗: the file name marks it
          as a bad dump. Hacks, translations and fixed dumps get no mark. Turn them off in Settings > Display > Dump Check Marks.
        
      
        Covers or the intro picture are missing on a 4MB console
        
        The menu leaves extras out rather than run out of memory. Settings > System > Memory says what; the Latin
          character set (Settings > System) frees the most.
        
      
        Reporting a problem
        
        Open an issue on GitHub: the form asks for your setup. A
          photo of the screen and the debug log help the most.
