; Popular N64 hacks: draft for the Companion's Hacks tab (step 3)
;
; Fill in the blanks (?) and change anything that's wrong. Lines starting
; with ; are notes and are ignored. One block per hack, starting with its
; name in [brackets].
;
;   keep          yes / no   (no = leave it out of the list)
;   base          the game it was made from, and that game's code (US)
;   code          the code the menu will know it by (X + two letters + E),
;                 the same on every card; change it if you like, but keep
;                 each one different
;   made_by       the person or team
;   year          the year it came out (or of the version people play)
;   players       1-4
;   expansion_pak needed / not needed / ?
;   real_n64      yes / no / which version works / ?  ("collection": the
;                 version in the archive.org "n-64-hacks-onism" set you sent)
;   file_words    words that are usually in the file's name, so the page
;                 can suggest the match (you still confirm it)
;   notes         anything else worth knowing (optional)
;
; Descriptions: I'll write a short one for each hack you keep, in our own
; words. If you want to give one yourself, add a line: description = ...
;
; Covers stay yours: the list never includes pictures.
